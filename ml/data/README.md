# 데이터 규칙

실제 원본 이미지와 개인정보는 이 저장소에 넣지 않습니다.

`manifest.example.jsonl`을 복사해 실제 manifest를 만들고, 실제 파일은 별도 스토리지에서 관리합니다.

반드시 `upload_id` 또는 촬영 세션 기준으로 train/validation/test를 나눕니다. 같은 업로드에서 추출된 연속 프레임이 서로 다른 split에 들어가면 검증 점수가 부풀려질 수 있습니다.

라벨은 사람이 검수한 데이터만 학습 데이터로 사용합니다. AI의 예측 결과는 검수 전까지 정답으로 취급하지 않습니다.
